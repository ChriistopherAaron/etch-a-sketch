# Etch-a-Sketch

A browser-based sketchpad built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum. This project demonstrates DOM manipulation, event listeners, and responsive layout styling using CSS Flexbox.

## Features

* **Dynamic Grid Generation:** Generates a custom grid layout rendered entirely using JavaScript and Flexbox.
* **Interactive Drawing:** Click and drag across the canvas to draw smoothly on the grid.
* **Grid Size Controls:** Change grid resolution using the interactive range slider or the popup prompt button (up to 100x100 max).
* **Grid Lines Toggle:** Easily turn grid borders on and off with the UI toggle button.
* **Responsive Layout:** Automatically scales grid cells so the canvas maintains a fixed size regardless of resolution.

## Built With

* HTML5
* CSS3 (Flexbox, CSS Custom Properties)
* JavaScript (DOM Manipulation, Event Handling)
